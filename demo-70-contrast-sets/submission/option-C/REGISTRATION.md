**Title:** Contrast-Set Growth Rates Across Adjacent Time Windows

**Abstract (DRAFT):** An item that is rare in one time window and common in the next is an emerging contrast set. This article specifies support in each window, a growth-rate ratio, and the two thresholds that mark an item as emerging, and it compares that rule with a global top-frequency baseline that ignores time. The contribution is a data-mining measurement for temporal itemsets, including security-relevant event codes when those codes appear in a publicly licensed trace. Later confirmatory traces would be taken only from collections whose licences have been checked, for example research releases from the Canadian Institute for Cybersecurity after the licence text on the chosen release has been recorded. A companion teaching demonstration scores eight labelled synthetic window pairs. No campaign finding about a live network is claimed here.

**Keywords:** contrast set mining, emerging patterns, temporal data mining, growth rate, support
