**Title:** Sequential Covering Decision Lists for Lexical URL Features

**Abstract (DRAFT):** A sequential covering algorithm grows an ordered decision list by repeatedly selecting the single binary feature whose positive rule has the highest precision on the still uncovered examples, then removing the examples that rule covers. This article specifies that learner, the default rule that remains when no unused feature improves precision, and the accuracy of the resulting list on a fixed table of lexical URL features. The contribution is an interpretable symbolic learner, not a crawling study and not a measurement of live phishing sites. Public feature tables whose licences permit research use, including the UCI Phishing Websites table once its current licence statement has been re-checked, are identified as later confirmatory substrates. A companion teaching demonstration learns a list from eight labelled synthetic rows. No accuracy figure for an external table is claimed here.

**Keywords:** rule learning, sequential covering, decision lists, interpretable models, lexical features
