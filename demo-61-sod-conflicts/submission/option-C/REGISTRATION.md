**Title:** Separation-of-duty Conflicts in Role-Based Access Control

**Abstract (DRAFT):** Periodic access recertification is a standard IT-audit control, yet recertification records do not by themselves reveal whether mutually exclusive permissions remain combined in a single user's effective set. This article specifies a deterministic procedure that reconstructs each user's effective permission set from role membership and role-permission assignments, then reports every pair of permissions that violates a declared segregation-of-duties constraint. The procedure uses only set membership tests; it does not apply machine learning, cryptology or blockchain methods. The analysis is specified for public role-based access-control examples published by NIST and for any organisation's own recertification extract released under a licence that permits research use. A companion teaching demonstration exercises the same procedure on a labelled synthetic policy of eight users. No empirical finding about a live system is claimed here.

**Keywords:** access control, segregation of duties, role-based access control, IT audit, control effectiveness
