**Title:** Anytime Search for Minimum-Uncovered Patrol Allocations

**Abstract (DRAFT):** A defender who may occupy only k vertices of a graph seeks an allocation that covers as many enumerated attacker paths as possible. This article treats that task as a combinatorial search problem: the state space is the set of k-subsets, the objective is the number of uncovered paths, and a greedy baseline repeatedly selects the vertex that covers the most still-uncovered paths. Exhaustive enumeration on small graphs provides a complete reference against which the greedy incumbent can be compared at a declared expansion budget, which is the sense in which the search is anytime. Later confirmatory instances would be taken only from publicly licensed graph collections, for example SNAP graphs whose individual licences have been checked. A companion teaching demonstration searches eight labelled synthetic graphs. No claim is made about any real facility.

**Keywords:** heuristic search, security games, patrol allocation, combinatorial optimisation, anytime algorithms
