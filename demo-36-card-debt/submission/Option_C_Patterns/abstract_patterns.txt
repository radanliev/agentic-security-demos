Public model repositories constitute critical digital infrastructure for distributing open-weight artificial intelligence models. While model cards serve as primary instruments for algorithmic transparency, whether documentation practices scale with model usage remains an open empirical question. Here, we present a comprehensive census of safety documentation across 809,703 model cards and 48,247 supply-chain lineage edges on the Hugging Face Hub, encompassing 2.47 billion downloads. Evaluating a pre-registered popularity hypothesis, we find the popularity gap is falsified on the registered binned estimator (-2.9 percentage points). On the unregistered row-level vector, the download-weighted safety rate (38.40%) exceeds unweighted rates (27.19%) by 11.21 points, but the 95% bootstrap interval ([-1.67, +24.68] points) spans both boundaries and is indeterminate. Extreme Value Theory indicates repository downloads follow an infinite-variance Pareto distribution (Hill tail index alpha = 0.98 <= 2), causing weighted metrics to be hypersensitive to individual corporate releases: omitting the top model alone swings the weighted safety rate by 7.20 percentage points. Furthermore, derivative lineages exhibit severe documentation decay, with an 83.46% license omission rate on merges. These findings reveal structural vulnerabilities in naive repository metrics, establishing the necessity of tail-trimmed estimators and provenance tracking for data stewardship in open AI ecosystems.
