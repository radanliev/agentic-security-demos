## 2. Formatting & Template Compliance

- [ ] **Document Format**: IEEE/ACM Conference Proceedings format.
- [ ] **Page Limit**: Maximum **10 pages** of main technical content, plus up to **2 pages** of references.
- [ ] **Software Engineering Relevance**: Explicitly highlights software supply chain mechanics, component reuse, and software maintenance across the model registry ecosystem.

---

## 3. Double-Blind Anonymity Integrity

- [ ] **Author Disclosures**: No author names, institutional affiliations, or acknowledgments in text or PDF properties.
- [ ] **Self-Citations**: Written in the third person without identifying pronouns.
- [ ] **Artifact Links**: Anonymous repository URLs without developer git commit history.
- [ ] **Automated Anonymity Gate**: Validated via `scripts/check_anonymity.py` with zero findings.

---

## 4. Policy Compliance & Ethical Standards

- [ ] **Dual Submission Rule**: Original, unpublished work; confirmed that no other conference or journal review is ongoing.
- [ ] **Conflict of Interest (COI)**: Fully declared according to ACM/IEEE guidelines.
- [ ] **Open Science & Reproducibility**: Data collection scripts and replication instructions prepared for Artifact Evaluation.
