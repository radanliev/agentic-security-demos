# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, safe, and inclusive environment for all contributors and learners, regardless of experience level, identity, or background.

## Our Standards

### Expected Behavior

- **Be respectful and constructive** in discussions
- **Assume good intent**; ask clarifying questions
- **Focus on educational value and safety**
- **Credit sources** and prior work appropriately
- **Report safety concerns privately** (see SECURITY.md)
- **Welcome newcomers** and help them contribute

### Unacceptable Behavior

- Harassment, insults, or discriminatory language
- Publishing private research data, credentials, or API keys
- Adding tests that access external networks
- Including executable malware or exploit code
- Presenting teaching results as validated research
- Disruptive behavior in discussions or PRs

## Enforcement

Violations may result in:
- PR rejection or request for changes
- Comment removal or editing
- Temporary or permanent repository access restrictions

Decisions are made by maintainers and are final.

## Reporting

Report violations to the maintainers via:
- Private GitHub message to maintainers
- Email: conduct@agentic-security-demos.example (placeholder)

All reports are handled confidentially.
