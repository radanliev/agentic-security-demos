Generated by `real/run_real.py` on 2026-10-26. Data are real public records (see DATA_SOURCES.md); nothing here is simulated. The bundled `fixtures/` remain SYNTHETIC teaching fixtures and are not used in these numbers.

## Credentials requested by MCP servers in the official registry (7552 servers)

- Servers that ask the user for at least one credential: 1778 (24%)
- Median credentials per such server: 1.0
- Credential families: other: 2051, LLM API key: 8, Database credential: 5, Google credential: 5, GitHub token: 1

Registry metadata names the credential but not its scope (e.g. a GitHub token is not tied to read-only scopes). That gap is itself the finding relevant to scope creep: the registry gives users no machine-readable statement of least privilege. Whether granted tokens exceed what tools use is not measurable from this data.

**Coverage caveat:** the fetch stopped at a 20,000-entry paging cap (20,100 entries fetched), so the census may be incomplete; raise the cap in `real/run_real.py` before quoting totals.
