# AI-agent attribution

Development of this repository included assistance from AI coding agents. Each
agent's contributions are credited in the commit history via `Co-authored-by:`
trailers (visible in `git log` and on the GitHub commit pages).

Agent conventions used across these projects:

    Co-authored-by: Google Antigravity <noreply@google.com>
    Co-authored-by: ZCode <radanliev+zcode@yahoo.com>

Other agents appearing in this repository's and the wider project family's
histories include Claude (Anthropic), Cursor, and GitHub Copilot; `git log`
is the authoritative per-repository record. All agent assistance was directed
and reviewed by the repository owner.
