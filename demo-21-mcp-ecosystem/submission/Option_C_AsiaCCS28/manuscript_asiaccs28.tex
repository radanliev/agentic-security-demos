\begin{abstract}
The Model Context Protocol (MCP) establishes a standardised web application interface connecting autonomous language model agents to external tools and microservices. We present an empirical security measurement of the official MCP registry across 126,847 version records and 37,815 distinct servers. Our study reveals significant attack surfaces: 61.89\% of registered servers declare remote HTTP endpoints, 56.96\% operate purely as remote web services without installable packages, and 3,679 endpoints demand confidential headers marked \texttt{isSecret}, binding ambient credentials to outbound web requests. Across 89,032 publication-ordered version transitions, releases arrive rapidly (median interval 0.8 days, 52.4\% within 24 hours). Longitudinal tracking reveals 1,353 transitions modifying remote URLs, with 52.4\% altering destination hostnames and 36.1\% crossing administrative eTLD+1 boundaries, predominantly migrating to multi-tenant serverless or PaaS platforms. Syntactic pattern screening across 40,672 tool descriptions yields a 1.25\% flag rate, but recovers only 6.2\% of benchmark prompt injection attacks while flagging benign documentation in 89.2\% of real-world hits, proving syntactic filters insufficient as security boundaries. We propose three architectural defences---origin-bound credential scoping, out-of-band manifest attestations, and registry domain lifecycle verification---to secure agentic tool execution.
\end{abstract}

\section{Introduction}
Autonomous agent systems increasingly rely on external tool execution protocols to carry out complex operations. The Model Context Protocol (MCP) has become a prominent open standard enabling language models to discover, invoke, and coordinate tools. However, the exposure of remote HTTP endpoints, secret headers, and version migrations introduces substantial security challenges.

\section{Threat Model and Attack Surface}
We formalise the threat model of unverified remote tool endpoints in agentic systems, examining credential leakage via ambient headers, tool poisoning via description manipulation, and domain migrations.

\section{Empirical Registry Measurement}
Across 126,847 records and 37,815 servers, we quantify remote service prevalence, Tranco domain ranking distribution, and confidential header declarations.

\section{Architectural Defences}
We design and evaluate origin-bound credential scoping, out-of-band manifest attestations, and domain lifecycle verification to prevent unauthorized capability expansion and credential harvesting.
