## 2. Formatting & Scope Compliance

- [ ] **Document Class**: ACM primary template (`\documentclass[sigconf,anonymous,review]{acmart}`).
- [ ] **Page Limit**: Short paper budget (typically 4–6 pages main text excluding references/appendix).
- [ ] **Measurement Focus**: Tight presentation focused on the core measurement finding (soft-404 prevalence, validation gate, and frontier bias).
- [ ] **Anonymity**: Full double-blind review compliance (no author identities, affiliations, or identifying repository links).

## 3. Ethics & Responsible Measurement

- [ ] **Data Sources**: Secondary analysis of public Common Crawl WARC data; no aggressive or intrusive active probing.
- [ ] **Reproducibility**: Artifact and script links points to anonymised git repositories with single-command reproduction instructions.
- [ ] **Dual Submission Rule**: Strictly enforced sequential policy — no overlapping submissions between Plan A, Plan B, and Plan C.
