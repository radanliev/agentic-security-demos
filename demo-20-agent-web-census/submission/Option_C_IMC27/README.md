This package represents a tertiary sequential fallback. It remains **dormant** and will only be activated if the paper has been rejected sequentially by:
1. The Web Conference 2027 (Plan A: Research Track long paper), and
2. The Web Conference 2027 Short Paper track (Plan B) or author decision to retarget directly to IMC.

Under no circumstances may this manuscript be submitted concurrently while under evaluation at WWW'27.
