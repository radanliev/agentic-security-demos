**Title:** Multi-Source Linkage and Severity Disagreement in Public Vulnerability Advisories

**Abstract (DRAFT):** The same vulnerability identifier can appear in more than one public advisory database with disagreeing severity labels or product strings. This article specifies an entity-resolution procedure that links records by exact vulnerability identifier and then measures two data-quality events: unequal severity strings, and product-token sets whose Jaccard similarity falls below one. The contribution is a knowledge-and-data engineering measurement of multi-source disagreement, not a scanner and not a patch lifecycle study. The public National Vulnerability Database JSON feeds are United States government works, and the GitHub Advisory Database is published under CC-BY-4.0; both are identified as later confirmatory sources. A companion teaching demonstration links eight labelled synthetic advisory pairs. No disagreement rate about the live feeds is claimed here.

**Keywords:** entity resolution, data quality, vulnerability databases, record linkage, knowledge integration
