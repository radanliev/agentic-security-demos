# Citation

## How to Cite

If you use these materials in teaching or research, please cite:

```bibtex
@software{agentic-security-demos,
  title = {Agentic Security Demos: Teaching Modules for Agentic AI Security},
  author = {Agentic Security Demos Contributors},
  year = {2024},
  version = {0.1.0},
  url = {https://github.com/agentic-security-demos/agentic-security-demos},
  note = {Educational materials for teaching agentic AI security concepts}
}
```

## APA Style

Agentic Security Demos Contributors. (2024). *Agentic Security Demos: Teaching Modules for Agentic AI Security* (Version 0.1.0) [Computer software]. https://github.com/agentic-security-demos/agentic-security-demos

## IEEE Style

[1] Agentic Security Demos Contributors, "Agentic Security Demos: Teaching Modules for Agentic AI Security," v0.1.0, 2024. [Online]. Available: https://github.com/agentic-security-demos/agentic-security-demos

## Citation File

Machine-readable citation metadata is available in [CITATION.cff](../CITATION.cff) following the [Citation File Format](https://citation-file-format.github.io/).

## When to Cite

Please cite this work when:
- Using demos in academic courses
- Referencing concepts in publications
- Building upon the framework
- Using fixtures or methodologies in research
